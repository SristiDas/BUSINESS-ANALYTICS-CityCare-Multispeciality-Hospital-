# CityCare Multispeciality Hospital, Jaipur
### Hospital Business Analytics | Power BI Capstone Project

## Project Overview

This project presents a Hospital Business Analytics dashboard developed using Microsoft Power BI for CityCare Multispeciality Hospital, Jaipur.

The project focuses on presenting hospital performance information through an interactive dashboard, supporting analytical exploration, identifying business insights, and translating findings into actionable recommendations.

## Project Objectives

- Present hospital performance through an interactive Power BI dashboard.
- Explore hospital-related metrics and trends.
- Interpret dashboard findings through structured analytical questions.
- Identify potential operational and business improvement opportunities.
- Develop actionable recommendations to support management decision-making.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization
- Microsoft PowerPoint

## Project Deliverables

1. **Power BI Dashboard (.pbix)** – Interactive hospital analytics report.
2. **Complete Dashboard PDF** – Exported dashboard for viewing and reference.
3. **Project Presentation (.pptx)** – Presentation of the capstone project.
4. **Seven Questions and Three Recommendations (PDF)** – Analytical questions and corresponding business recommendations.

## Business Analysis Approach

The project follows a practical business analysis approach:

1. Review the available hospital dashboard information.
2. Explore relevant business metrics and performance patterns.
3. Formulate analytical questions based on dashboard findings.
4. Interpret the findings from a business perspective.
5. Develop recommendations to support operational improvement and management decisions.

## Key Learning Outcomes

- Developing interactive dashboards using Power BI.
- Understanding business-oriented data visualization.
- Interpreting analytical findings.
- Connecting dashboard insights with business decisions.
- Communicating recommendations through structured presentations.
